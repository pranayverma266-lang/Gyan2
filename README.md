# Gyan2
GyanX ek modern, mobile-friendly school learning web app hai jo students ki padhai ko aasaan, smart aur interesting banata hai. Ye Hindi aur English, dono bhashaon mein kaam karta hai, isliye har student ise apni pasand ki bhasha mein use kar sakta hai. App mein student apne account se login karke class aur subject ke hisaab se apna dali.
